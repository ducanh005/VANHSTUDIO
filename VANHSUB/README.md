# VanhStudio

**VanhStudio** — Ứng dụng desktop sản xuất video, chuyển giọng nói & hình ảnh thành phụ đề, dịch thuật ngữ cảnh và lồng tiếng AI, tối ưu cho nội dung tiếng Việt.

## Công nghệ

- Electron + Nextron
- Next.js + React 19
- TypeScript + Tailwind CSS
- Whisper.cpp / Faster-Whisper, RapidOCR / Tesseract.js, FFmpeg, Edge TTS / TikTok TTS / VietTTS, Google Gemini API

## Phát triển

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
